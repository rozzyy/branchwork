# M11 — Browser screen: Implementation Plan

> Native execution (user: "lanjutkan fitur selanjutnya"). One stage commit after the checkpoint.

**Goal:** A Browser screen with tabs and a free address bar. **Spec:** `docs/superpowers/specs/2026-11-14-m11-browser-design.md`.

## Global Constraints
- Cargo `tauri/unstable` (multi-webview). Browser webviews `browser-<window>-<tab>` get no capability (`default.json` lists `webviews`, not `windows`).
- Only http(s) loads (TS `toAddress` + Rust `parse_url`); navigation guard allows http/https/about for browser webviews only.
- Tabs are window-scoped (`browserTabs`), max 20.

## Review Focus
1. Remote pages cannot reach Branchwork IPC.
2. `javascript:` / `file:` / `data:` / `tauri:` never load.
3. A window can only drive its own browser webviews.
4. Native page hides while app overlays are open.
5. Browser mode (e2e) shows the chrome without a native page.
