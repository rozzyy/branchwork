Branchwork design system · v0.1 · prototype

Calm, readable, reachable

Three principles: one place for context (always clear where you are), show tools when they're needed (banners, not hidden menus), and accessible by default (WCAG 2.2 AA contrast, visible focus, keyboard everywhere, status never by color alone). Switch the theme (☾ / ☀ in the top bar) to test both modes.

Color: surfaces & text

Surfaces are solid (no glass). The contrast ratio is computed live in the browser against --surface; text must be ≥ 4.5:1.

Color: accent & status

The accent keeps the current app's blue (hue 250). Purple is reserved for anything AI/agent.

Accessibility rules

ContrastDo body text ≥ 4.5:1, icons/borders that carry meaning ≥ 3:1. Don't put text on transparent glass.
KeyboardDo make everything reachable with Tab, focus visible, Esc closes overlays. Don't use single-key shortcuts without a modifier (WCAG 2.1.4); 1–9 → ⌘1–⌘7.
StatusDo pair color with an icon and text ("⚠ 2 conflicts"). Don't rely on a colored dot alone.
Scroll & sizeDo keep scrollbars visible and support "Large" text and density. Don't hide scrollbars or use text below 12px.
LabelsDo give icon buttons an aria-label + tooltip, and announce banners and statuses (role=status).
MotionDo keep animations short (150ms) and turn them off under prefers-reduced-motion.
